# 소화계 협동 대작전 💩

중2 과학 **Ⅵ. 동물과 에너지 - 1. 소화와 순환 · 02 소화계의 구조와 기능**
두 명이 한 팀이 되어 **하나의 소화계**를 함께 움직이는 2인 협동 웹게임.
목표는 음식물을 제대로 소화·흡수해서 **예쁜 똥(브리스톨 3~4형)** 을 만드는 것.

> **학습 범위** — 이번 차시(소화계의 구조와 기능) 교과서 내용만 다룹니다.
> 소화관/소화샘 구분 · 각 소화액이 어디서 만들어져 어디로 가는가 ·
> 작은창자(소화 + 흡수) · 큰창자(물 흡수).
> **모세혈관/암죽관으로 나뉘는 흡수는 다음 차시라 게임에 넣지 않았습니다.**

---

## 1. 실행 방법

1. 압축을 풀고 **`start-windows.bat`** (맥은 `start-mac.command`) 실행
2. 검은 창에 뜨는 주소를 **칠판에 적기**
   ```
   학생 태블릿 : http://192.168.0.xx:8080
   선생님 화면 : http://192.168.0.xx:8080/teacher.html
   ```
3. 학생들이 디벗(태블릿) 브라우저로 그 주소에 접속

- **Node.js LTS 필요.** 학교 노트북이라 설치가 막히면 nodejs.org 의 Windows **ZIP** 을 받아
  그 안의 `node.exe` **한 파일만** 게임 폴더에 복사해도 됩니다.
- **`npm install` 필요 없음.** WebSocket 서버를 직접 구현(`ws-lite.js`)했고 외부 라이브러리가 없습니다.
- 인터넷 없이 **교실 와이파이만으로** 동작합니다.

---

## 2. 게임의 뼈대 — 왜 두 명이어야 하는가

소화는 **소화관(음식물이 지나는 길)** 과 **소화샘(소화액을 만드는 기관)** 이
톱니바퀴처럼 맞물려야 일어납니다. 그래서 역할을 둘로 나눴습니다.

| | 🍚 **소화관 담당 (1P)** | 💧 **소화액 담당 (2P)** |
|---|---|---|
| 다니는 곳 | 입 → 식도 → 위 → 작은창자 → 큰창자 | 침샘 · 위샘 · 간 · 쓸개 · 이자 · 장샘 |
| 하는 일 | 씹기 · 꿈틀운동 · 휘젓기 · 흡수 · 물 조절 | 소화액을 만들어 **올바른 기관으로 보내기** |

**한쪽만 잘해서는 절대 소화가 되지 않습니다.**

- 침이 없으면 → 아무리 씹어도 **녹말이 소화되지 않고**, ★ **입이 말라 음식물을 옮기기조차 어렵다**
- ★ 식도 근육이 막히면 → 소화관 담당은 아무것도 못 한다. **짝꿍이 분류 문제를 맞혀야 뚫린다**
- 위액이 없으면 → 아무리 저어도 **단백질이 소화되지 않는다**
- 쓸개즙이 없으면 → 이자액이 아무리 많아도 **지방이 분해되지 않는다** (유화가 먼저다)
- 소화가 덜 된 영양소는 융털로 **흡수되지 않는다**
- 흡수 못 한 영양소가 장에 남으면 **물을 끌어당겨 설사**가 된다

소화액은 시간이 지나면 줄어들기 때문에 2P는 **계속 공급**해야 하고,
1P는 부족할 때 📢 신호 버튼으로 알려야 합니다.

---

## 3. ★ 이 게임의 핵심 학습 장치 — 쓸개즙의 경로

소화액 담당은 미니게임으로 소화액을 만든 뒤,
오른쪽 **인체 소화계 그림**(교과서처럼 실제 위치 + 이름표)을 보고
아래 선택기에서 **목적지를 좌우로 골라** [분비] 합니다.
만든 소화액은 **굳기 전에** 보내야 하므로 어디로 보낼지 빨리 판단해야 합니다.

| 소화액을 만드는 곳 | 보내야 하는 곳 |
|---|---|
| 침샘 | 입 |
| 위샘 | 위 |
| **간** | **쓸개** ← 여기가 함정 |
| **쓸개** | **작은창자** |
| 이자 | 작은창자 |

- **간 → 위**로 보내면 배탈 +26, 화면이 흔들리고 두 사람 모두에게 경고가 뜹니다.
  > "간이 만든 쓸개즙을 위로 보냈습니다! 쓸개즙은 반드시 쓸개에 저장했다가 작은창자로 갑니다."
- **간 → 작은창자 직행**도 오답입니다. 반드시 쓸개를 거쳐야 합니다.
- **식도·큰창자**로 보내면 "여기에는 소화샘이 없습니다" 안내가 뜹니다.
- 배탈이 70을 넘으면 **역류**가 일어나 진행이 뒤로 밀리고,
  100이 되면 **급성 소화불량(F등급)** 으로 게임이 끝납니다.

## 4. 조작

| | 태블릿 | 노트북(시연) |
|---|---|---|
| 소화관(1P) 이동 | 화면 **왼쪽 아래를 끌기** | ← → |
| 점프 | 오른쪽 아래 초록 버튼 | Space / ↑ |
| 잡기·던지기·문지르기·누르기 | 오른쪽 노란 버튼 | Z |
| 소화액(2P) | 화면을 직접 터치 (미니게임마다 다름) | 마우스 |

### 미니게임 10종 — 전부 다른 방식

| 단계 | 🍚 소화관 (1P) | 💧 소화액 (2P) |
|---|---|---|
| **입** | ★ **침이 마르면 음식물이 잘 안 움직입니다** — 몸으로 밀어도 거의 안 굴러가고, 들면 발이 느려지고, 던져도 멀리 안 갑니다. 짝꿍이 침을 보내 줘야 합니다. ★ **어금니가 맞물리는 자리는 혀보다 한 단 낮은 구덩이**입니다. 혀 위에서 **몸으로 부딪쳐** 조각을 밀어 구덩이로 떨어뜨리면 어금니가 씹습니다(밀기 버튼 없음). 2~3번 씹히면 **그 구덩이 자리에 그대로** 남으므로, **어금니가 열린 틈에 뛰어 내려가 [줍기] → 다시 점프해서 올라와야** 합니다. 맞물릴 때 구덩이 안에 있으면 체력이 깎입니다 | **침 받기** — 침샘에서 튀어나오는 침을 컵으로 받습니다. 섞여 나오는 **회색 공기방울은 피해야** 합니다 |
| **식도** | 음식물 **바로 뒤**의 근육을 조이기. 앞쪽을 조이면 역류. ★ 가끔 근육이 **막히는데, 소화관 담당은 스스로 뚫을 수 없습니다** — 짝꿍이 분류 문제를 맞혀야 뚫립니다. 막힌 채 오래 두면 음식물이 조금씩 역류합니다 | **소화관 / 소화샘 분류** — 기관 이름 카드를 좌우로 밀어 분류. ★ **짝꿍의 근육이 막히면 화면 테두리가 빨갛게 깜빡이고, 한 문제만 맞히면 뚫어 줍니다**(그때는 제한 시간도 넉넉해집니다) |
| **위** | ★ **위액에 닿으면 기절.** ★ **몸으로 밀어도 덩어리는 꿈쩍하지 않습니다** — 반드시 **[잡기]로 들어 [던지기]** 로 위액에 빠뜨려야 합니다. **위 천장에서 위액 방울이 떨어지고**(붉은 예고 후), 표면에서도 방울이 튀어오릅니다. 위액 위에 쓸 수 있는 덩어리가 3개 미만이면 **식도에서 계속 더 내려옵니다** | ★ **위액 만들기 하나에만 집중** — 위샘 3개가 **번갈아 반짝입니다.** 반짝이는 위샘의 **초록 구간에서 눌러야** 하고, 다른 위샘을 누르면 헛일입니다. 3번 모으면 위액 한 병 (쓸개즙 만들기는 작은창자 단계에서만 합니다) |
| **작은창자** | ★ **꼬불꼬불한 미로**(위에서 내려다보는 화면, 중력 없음). 처음부터 **음식물 덩이 6개**가 관 여기저기에 흩어져 있습니다. 소화액 웅덩이 **3곳**으로 굴려 가서 **[문지르기] ×4** → 작은 영양소 → 그 자리 **위·아래 관벽의 융털**로 밀면 바로 흡수. ★ **소화되지 않은 큰 덩이를 관벽에 부딪히면 체력이 깎입니다** — 벽에 닿지 않게 조심히 굴려야 합니다. 소화액이 없으면 덩이가 거의 굴러가지 않습니다 | ★ **소화액 관 네트워크** — ★ **간(쓸개즙) → 이자(이자액) → 간 … 번갈아** 만듭니다(차례가 아닌 기관은 눌러도 안 됩니다). 간은 초록 방울 탭, 이자는 연타로 만들고, 만든 방울을 **하나로 이어진 관을 따라 끌어서** 보냅니다. 관 끝은 **위 · 쓸개 · 작은창자** 세 곳 — 어디로 보낼지 스스로 골라야 하고, **관 밖으로 나가면 새어 나가 처음부터**. 쓸개에 저장된 쓸개즙은 **다시 끌어서** 위로 갈지 작은창자로 갈지 또 고릅니다. 간에서 만든 방울에는 **「쓸개즙」** 이라고 적혀 있습니다 (기관 이름 「쓸개」와 헷갈리지 않도록) |
| **큰창자** | ★ 찌꺼기가 **한 칸에 최대 18초** 갇힙니다(칸 4개). 물길이 뚫리면 **"N.N초 동안 흡수하세요!"** 가 뜹니다. 찌꺼기 위에서 버튼을 **꾹 누른 채 스스로 초를 세다가 그 초에 맞춰 뗍니다** — ★ **화면 어디에도 초시계도, 남은 시간도 없습니다.** ★ **칸마다 딱 한 번**이며, ★ **한 번 재고 나면 남은 시간을 기다리지 않고 바로 다음 칸으로 넘어갑니다.** 잘 맞추면 그 칸 목표를 넘고, 0.5초쯤 어긋나면 모자라며, 1.4초를 넘으면 한 방울도 안 빠집니다 | **물길 파이프 퍼즐** — 칸마다 **18초 안에** 조각을 돌려 입구→출구 연결. 못 풀면 그 칸은 그냥 지나가고 물을 못 뺍니다 |

> 큰창자의 칸별 목표는 **작은창자를 지나온 찌꺼기의 실제 수분**에서 역산합니다.
> 배탈이 심하면 칸 타이머가 더 빨리 흘러 물을 뺄 시간이 줄어듭니다 — 설사의 실제 원리입니다.

## 4-0. 기관마다 있는 체력 ★

소화관 담당에게는 **기관마다 체력바**가 있습니다(화면 오른쪽 위).
어금니에 눌리거나, 위액·떨어지는 방울에 닿거나, 작은창자에서 관이 조여들 때 깎입니다.

**체력이 0이 되면 그 기관에서는 더 이상 일할 수 없습니다.**
이때 **짝꿍이 그 기관에 알맞은 소화액**(큰창자는 다음 칸의 물길)을 보내 주면 회복됩니다.
식도에는 소화액이 없으므로 시간이 지나면 저절로 회복됩니다.

## 4-1. 소화계 모식도 + 목적지 터치

소화액 담당 화면의 오른쪽에는 **소화계 모식도**(박스 + 이름)가 있습니다.
파란 세로줄이 소화관, 주황 박스가 소화샘이고 점선 화살표가 "어느 소화액이 어디로 가는가"를 보여 줍니다.

**보낼 곳은 모식도를 그냥 터치하면 됩니다.** (아래 6칸 버튼으로 골라도 되고,
플라스크를 끌어다 기관 위에 놓아도 바로 보내집니다.) 고른 기관은 노랗게 깜빡이고, [분비]로 보냅니다.
짝꿍이 급하게 필요로 하는 기관은 **빨갛게 「급구!」** 로 깜빡입니다.

대기실에는 **기관 도감**(기관 그림 + 이름)이 있어 게임 전에 눈에 익힐 수 있습니다.

## 4-2. 역할 바꾸기

`역할 바꾸기 요청`을 누르면 **짝꿍 화면에 요청창**이 뜨고,
짝꿍이 **수락해야** 두 사람의 역할이 맞바뀝니다 (게임 시작 전에만 가능).

## 4-3. 다시 하기 ★

결과 화면의 `🔁 다시 하기 (방 그대로)` 를 누르면 **짝꿍 화면에 요청창**이 뜨고,
수락하면 **방 번호를 그대로 둔 채 대기실로** 돌아갑니다.
방을 새로 만들 필요가 없고, 거기서 역할도 다시 바꿀 수 있습니다.

## 4-4. ★ 시간이 지나도 자동으로 안 넘어갑니다

**예전에는** 단계마다 제한 시간이 있어서, 시간이 다 되면 못 해도 다음 기관으로 넘어갔습니다.
그래서 아이들이 **"우리가 해결했다"** 고 착각했습니다. 지금은 다릅니다.

- 각 단계에는 **통과 조건**이 있고, **그 조건을 채워야만** 다음 기관으로 갑니다.
- 조건을 못 채우면 **그 기관에 계속 머뭅니다.** 화면 위에 **무엇이 몇 개 모자란지** 계속 떠 있습니다.
  (예: `아직 덜 씹었습니다 (3/6)`, `녹말이 아직 소화되지 않았습니다 (12/30)`)
- `STAGES[].time` 은 이제 **제한 시간이 아니라 목표 시간**입니다.
  넘기면 화면 시간이 주황색으로 변하고 `목표 시간을 넘겼습니다 — 통과 조건을 채워야 넘어갑니다!` 가 뜹니다.

| 기관 | 통과 조건 |
|---|---|
| **입** | 잘게 부순 조각을 **목구멍으로 5번** 넘기고 + **녹말이 침으로 소화**되어야 함 |
| **식도** | 음식물을 **위까지** 밀어 내려야 함 |
| **위** | 덩어리를 위액에 빠뜨려 충분히 섞고 + **단백질이 소화**되어야 함 |
| **작은창자** | 영양소를 **정해진 양만큼 소화하고 흡수**해야 함 |
| **큰창자** | **칸 4개를 다 지나고** + 수분이 목표 구간까지 빠져야 함. 물이 아직 많으면 ★ **큰창자를 한 바퀴 더 돕니다** (최대 3바퀴) |

### 등급은 **총 걸린 시간**으로

똥의 등급(S·A·B·C·D)은 이제 **다섯 기관을 통과하는 데 걸린 총 시간**으로 매깁니다.
목표 시간 합계(**4분 29초**) 대비 몇 배가 걸렸는지가 기준입니다.
한 판이 5분 안팎으로 끝나므로 **45분 수업에서 역할을 바꿔 두 판**을 할 수 있습니다.

| 등급 | 기준 |
|---|---|
| **S** | 목표의 0.85배 이내 (약 3분 49초 안쪽) |
| **A** | 1.15배 이내 |
| **B** | 1.5배 이내 |
| **C** | 2.0배 이내 |
| **D** | 그보다 오래 |

- 똥 모양이 3·4형이 **아니면** 아무리 빨라도 **C 이하**로 내려갑니다.
- 오분비를 3번 이상 하면 한 등급 더 내려갑니다.
- 배탈 100(급성 소화불량)은 그대로 **F**.

## 8. 자동 검증

```
node test/rules.mjs      # 과학 규칙 · 결과 판정 104항목
node test/net.mjs        # 2인 동기화 · 역할 바꾸기 · 다시 하기 39항목
node test/browser.mjs    # 실제 브라우저 2대로 10종 미니게임 전부 130항목 (playwright 필요)
```

`test/browser.mjs` 에는 **물길 퍼즐이 항상 풀 수 있는 판인지** 200번 검사하는 항목,
**결과 화면에 다음 차시 용어(암죽관·모세혈관)가 섞이지 않았는지** 확인하는 항목,
그리고 **10개 화면 전부에서 글자가 서로 겹치지 않는지**를 실제로 그려 보고
글자 상자를 비교해 자동으로 검사하는 항목이 들어 있습니다.

또한 ★ **시간이 지나도 단계가 자동으로 넘어가지 않는지**(목표 시간 +40초를 흘려 보내도
입에 그대로 머무는지), ★ **위의 발판이 실제로 점프해서 닿는 높이인지**
(점프 높이 = `jumpV² / 2g` 를 계산해 발판 그래프가 이어지는지 + 실제로 캐릭터를 조작해
맨 위 발판까지 올라가 보는지), ★ **던진 음식물이 발판 끝으로 순간이동하지 않는지**,
★ **큰창자 화면에 남은 시간이 아예 안 나오는지**(소스에 `roundT` 가 없는지),
★ **초를 맞추면 곧바로 다음 칸으로 가는지**, ★ **간·이자 차례가 번갈아 도는지**,
★ **목구멍 옆 구덩이에 빠져도 점프로 나올 수 있는지**(실제로 조작해 봅니다),
★ **침이 마르면 밀어도 잘 안 움직이는지**, ★ **막힌 식도 근육이 짝꿍의 정답으로만 뚫리는지**,
★ **소화액이 위액 7초 · 이자액 5초씩 일하는지**도 자동으로 확인합니다.

`test/rules.mjs` 에는 **완벽하게 협동한 플레이와 엉성한 플레이를 끝까지 시뮬레이션**해서
전자는 3~4형(S등급), 후자는 소화불량/설사가 나오는지 확인하는 항목이 들어 있습니다.

## 9. 게임 규칙에 담은 과학 (이번 차시 범위)

- 소화계 = **소화관**(입·식도·위·작은창자·큰창자·항문) + **소화샘**(침샘·간·쓸개·이자, 위는 스스로 위액 분비)
- 입 : 치아로 잘게 부수고 **침**에 의해 소화된다 → 게임에서도 침이 없으면 소화가 0
- 식도 : **음식물이 이동하는 통로일 뿐** → 소화액을 보내면 오답 처리
- 위 : **위액**을 분비하여 소화 → 위액이 묽으면 덩어리가 녹지 않음
- **간 → 쓸개 → 작은창자** : 간은 쓸개즙을 만들어 쓸개로 보내고, 쓸개가 저장했다가 작은창자로 분비
  → 간에서 작은창자로 직행하면 오답
- 이자 : 이자액을 만들어 **작은창자로** 분비
- 작은창자 : **① 소화액으로 영양소를 소화 → ② 소화된 영양소를 흡수** (2단계)
  → 소화되지 않은 큰 영양소를 흡수하려 하면 "흡수되지 않습니다"
- 큰창자 : **물을 일부 흡수**, 찌꺼기는 항문으로 배출
- 흡수되지 못한 영양소가 장에 남으면 물을 끌어당겨 묽어진다 / 장을 너무 빨리 지나가면 물을 못 뺀다 → 설사

> **모세혈관·암죽관으로 나뉘는 흡수는 다음 차시 내용**이라 일부러 넣지 않았습니다.
> 그 차시에 맞춰 확장하고 싶으면 `game-core.js` 의 `absorb` 처리에 통로 구분을 더하면 됩니다.
